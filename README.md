# Global Multi-Agent Development System

Hệ thống 5 AI Subagents chuyên trách cấp Global cho Google Antigravity:
1. **project-manager**: Điều phối trung tâm, lập kế hoạch, phân rã task, giám sát Quality Gate và báo cáo PO.
2. **backend-developer**: Database, API, Logic backend, Auth, Tối ưu hóa truy vấn, Bảo mật dữ liệu.
3. **frontend-developer**: UI Components, Responsive, Accessibility, Form validation, Tích hợp API, Trạng thái UX.
4. **qa-tester**: Thiết kế test, Automated Testing (Unit/Integration/E2E), Kiểm tra hồi quy, Tái hiện bug.
5. **code-reviewer**: Kiểm tra kiến trúc, Code smells, Lỗ hổng bảo mật, Git diff audit, Chặn scope creep.

Hệ thống hoạt động trên mọi dự án, tôn trọng rules và skills riêng của từng workspace.
